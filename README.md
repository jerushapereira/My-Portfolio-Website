# Jerusha Pereira Portfolio

Premium static portfolio website for Jerusha Pereira, focused on full-stack development, AI projects, hackathon work, and social impact.

## Files

- `index.html` - portfolio content and page structure
- `styles.css` - responsive visual design using the supplied color palette
- `script.js` - mobile navigation, project filtering, and reveal animations
- `netlify.toml` - optional Netlify static hosting config

## Before Publishing

Update these placeholders in `index.html`:

- `your-email@example.com`
- `https://www.linkedin.com/in/your-linkedin`
- `https://github.com/your-github`

You can also add a resume link in the contact section when the resume PDF is ready.

## Global Deployment Options

### GitHub Pages

1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Go to repository `Settings` -> `Pages`.
4. Choose `Deploy from a branch`.
5. Select the `main` branch and `/root`.
6. Share the generated public URL with recruiters.

### Netlify

1. Go to Netlify and choose `Add new site`.
2. Drag and drop this folder, or connect the GitHub repository.
3. Use `.` as the publish directory.
4. Netlify will create a global public URL.

### Vercel

1. Import the GitHub repository into Vercel.
2. Keep framework preset as `Other`.
3. Use the project root as the output directory.
4. Deploy and share the public URL.
